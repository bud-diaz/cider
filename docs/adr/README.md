# Architecture Decision Records

Each ADR records one decision: what was decided, what else was considered, and
what the project has to live with as a result.

An ADR is a historical record. Once merged it is not rewritten to match later
thinking — if a decision is reversed, the new ADR supersedes it and both stay.
